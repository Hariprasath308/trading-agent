\# TradeBot — User Guide



\## 1. What is TradeBot?



TradeBot is a \*\*Paper Trading Dashboard\*\*.



It analyzes stock-market data and displays a \*\*BUY, SELL, or HOLD\*\* signal without using real money.



\## 2. Why did we create this tool?



The main purpose is to make basic stock analysis easier and to practice trading without risking real money.



\*\*Simple explanation:\*\*



> Real money use pannama stock trading practice panna indha project pannom. Stock data-va analyze panni BUY, SELL, HOLD signal kudukkum.



\## 3. What Algorithm is Used?



TradeBot uses a \*\*Moving Average Strategy\*\*.



It calculates two Simple Moving Averages:



\* \*\*SMA 20\*\* — average closing price of the latest 20 periods.

\* \*\*SMA 50\*\* — average closing price of the latest 50 periods.



The strategy compares SMA 20 and SMA 50 to generate a trading signal.



\### Basic idea



```text

SMA 20 > SMA 50

&#x20;       ↓

Short-term trend is stronger

&#x20;       ↓

Bullish indication



SMA 20 < SMA 50

&#x20;       ↓

Short-term trend is weaker

&#x20;       ↓

Bearish indication

```



The dashboard then displays the signal generated by the configured trading strategy.



\## 4. How to Use TradeBot



1\. Open the TradeBot dashboard.

2\. View the stock table.

3\. Check the current price.

4\. Check SMA 20.

5\. Check SMA 50.

6\. Check the BUY / SELL / HOLD signal.

7\. Use the result for learning and paper-trading analysis.



\## 5. Dashboard Columns



| Column | Meaning                                  |

| ------ | ---------------------------------------- |

| Stock  | Stock symbol                             |

| Price  | Latest available stock price             |

| SMA 20 | 20-period moving average                 |

| SMA 50 | 50-period moving average                 |

| Signal | Signal generated by the trading strategy |



\## 6. What Do the Signals Mean?



\### BUY



The strategy identifies a condition that may support a buying signal.



\### SELL



The strategy identifies a condition that may support a selling signal.



\### HOLD



The strategy does not identify a new BUY or SELL condition.



\## 7. Example



```text

Stock: RELIANCE.NS

Price: 1310

SMA 20: 1302.34

SMA 50: 1301.98

Signal: HOLD

```



This means the dashboard analyzed the available market data and the current strategy condition is \*\*HOLD\*\*.
