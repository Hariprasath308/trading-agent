\# TradeBot



\## Paper Trading Dashboard



TradeBot is a paper-trading dashboard that analyzes selected NSE stocks using price data and a 20/50 Simple Moving Average strategy.



\### Features



\- Stock price analysis

\- SMA 20 calculation

\- SMA 50 calculation

\- BUY / SELL / HOLD signals

\- FastAPI backend

\- Next.js frontend

\- Paper trading only
